# تطبيق Old Permic OCR — Flutter

هذا المجلد تطبيق Flutter أصلي مستقل لتجربة كشف محارف البرمية القديمة. لا يعتمد على كود أو ثيم أو نموذج من مستودع `ocroldpermic` المحمي، ولا ينسخ أي محتوى من `shafeea_teacher`. البنية هنا مكتوبة من الصفر ومفتوحة المصدر.

## البنية

- `lib/domain`: كيانات الإصدار والكشف والنص المرتب ومنافذ التخزين والشبكة والاستدلال.
- `lib/application`: حالات الاستخدام، ومنها فحص الإصدار وتنشيطه مع single-flight وفاصل عشر دقائق.
- `lib/infrastructure`: محول GitHub العام ومخزن النموذج المرحلي/الذري ومحولات الشبكة والاستدلال المحلية.
- `lib/presentation`: واجهة عربية من اليمين إلى اليسار، الثيمات، الشريط الجانبي وتجربة الصورة.
- `lib/main.dart`: نقطة تركيب التطبيق وحقن الاعتمادات، وليست مكانًا لقواعد المجال.

## التحديث الآمن

يفحص التطبيق الإصدار عند الفتح والعودة إلى المقدمة، ثم يسمح بفحص تلقائي جديد كل عشر دقائق عندما توجد شبكة. زر **تحديث النموذج** موجود في الشريط الجانبي. لا يحدث التفعيل إلا بعد تحقق manifest، خريطة المحارف الـ38، حجم ملف ONNX، وSHA-256؛ ينزل الملف إلى `.part` ثم يبدّل مؤشر النسخة النشطة ذريًا. لا توجد خدمة خلفية تدّعي فحص Android بدقة كل عشر دقائق؛ هذا السلوك مقيد بدورة حياة التطبيق واتصال الشبكة.

## التشغيل والبناء محليًا

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

لإنشاء APK تجريبي محلي، يحتاج الجهاز إلى Flutter وAndroid SDK فقط:

```bash
flutter build apk --debug
# الناتج: build/app/outputs/flutter-apk/app-debug.apk
```

هذا APK تجريبي موقّع بمفتاح debug محلي ينشئه Android/Gradle. لا تحفظ مفاتيح release أو رموز GitHub في هذا المستودع. قراءة manifest العام لا تحتاج رمز وصول. لإنشاء release موقّع للتوزيع، ينفذ مالك الجهاز إعداد Android keystore خارج المستودع ويحقن أسراره في بيئة البناء فقط.

## حدود الإصدار الحالي

تجربة الصورة والواجهة وعقد التحديث موجودة، لكن تشغيل محرك ONNX native والتحقق على جهاز Android فعلي يتطلب بيئة Flutter/Android؛ لا تُعرض نتيجة OCR مصطنعة أو ترجمة غير موثقة. النموذج الحالي صناعي ومخصص للاختبار، وليس دليلًا على أداء تاريخي.

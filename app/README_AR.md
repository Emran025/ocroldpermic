# مشغّل OCR عام لتطبيق Flutter

هذا التطبيق مشغّل OCR محلي قابل لإعادة الاستخدام. اسم المستودع يعكس نقطة بدايته فقط؛ ولا يحمل التطبيق معرفة ثابتة عن البرمية القديمة أو أي أبجدية أخرى. الحزمة المثبتة هي التي توفر النموذج وخريطة الفئات إلى Unicode واللغة والخط وإعدادات المعالجة المسبقة.

## سير العمل

1. ثبّت حزمة OCR من ملف `.ocrpkg` محلي أو رابط حزمة أو رابط manifest عبر HTTPS.
2. اختر صورة من المعرض أو الكاميرا أو رابط صورة موثوق.
3. شغّل الاستدلال المحلي عبر ONNX Runtime.
4. راجع النص والكشفات والثقة وUnicode والبدائل التي أرجعها النموذج.
5. صحح النص دون فقدان الناتج الخام للنموذج.
6. صدّر TXT أو JSON بحثي أو CSV بالمحارف وبيانات القابلية لإعادة الإنتاج.

## الضمانات الأساسية

يتحقق المشغّل من مخطط الحزمة، وتوافق وقت التشغيل، وأبعاد الإدخال، وفهرس المحارف، وحجم الملف، وبصمة SHA-256. تُثبت التنزيلات في مجلد مرشح أولًا، ثم يُبدّل مؤشر النموذج النشط فقط بعد نجاح التحقق؛ ولذلك لا يؤدي تنزيل أو تحديث فاشل إلى تعطيل نموذج عامل. كما ترفض استيرادات ZIP المسارات غير الآمنة وتلتزم بحدود حجم واضحة.

بعد التثبيت يعمل OCR محليًا دون اتصال. يلزم الاتصال فقط لجلب الحزم أو الصور البعيدة أو فحص التحديثات.

## عقد الحزمة

راجع [OCR Package Contract v1](docs/OCR_PACKAGE_CONTRACT.md) للاطلاع على manifest الإصدار 1، وهيكل حزم `.ocrpkg`، وعقد YOLO v8، وبيانات التصدير البحثية.

## التشغيل

```bash
flutter pub get
flutter analyze

```

# Komi Abur / Old Permic — final collections

This package preserves every supplied collection and the previous generated collection without overwriting duplicates.

01_Original_Handwriting: complete 43-glyph handwriting family.
02_Original_Anbur: supplied Anbur family; 33 glyphs per style.
03_Modern_Permic: supplied modern family; 33 glyphs per style.
04_Previous_Generated: earlier generated Original/Bold/Italic family; 43 glyphs per style.

All filenames use U+XXXX.svg. See REVIEW.md for completeness details.
